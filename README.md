# Lumen Calc - downloads

Lumen Calc is a lighting design and analysis program for Windows: interior and site
lighting calculations, rendering, reports and AutoCAD export.

**Download the latest version from [Releases](../../releases/latest):**

- `LumenCalc-Setup-<version>.exe` - the installer (recommended). No administrator rights
  needed. Installed copies check this page for updates when they start and offer to install them.
- `LumenCalc-<version>-portable.zip` - no install: unzip anywhere and run `lumen_calc.exe`.
- `LumenCalc-User-Guide-<version>.html` - the User Guide (also built into the program: press F1).

Windows may say the installer is from an unknown publisher (it isn't code-signed yet):
choose **More info**, then **Run anyway**.

This repository holds releases only; the source code is kept privately.
